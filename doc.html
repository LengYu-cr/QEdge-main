QEdge 简介及脚本开发文档

基于 Xposed 的 QQ 扩展模块 · 脚本开发指南

简介
QEdge 是一个基于 Xposed 框架的 QQ 扩展模块，允许开发者通过编写脚本扩展 QQ 的功能。脚本引擎基于 BeanShell，支持 Java 8 语法。
脚本目录位于 QQ 数据目录下的 QEdge/plugin 文件夹中。
开发环境说明
脚本运行于 Modern BeanShell 环境，支持 Java 8+ 特性。编写时请遵循以下规范：
  • 属性访问：推荐使用成员符 . 直接访问对象属性（如 msgData.msg），无需调用 Getter 方法。
  • 方法访问：无需强制类型转换即可自动调用对应签名的方法和字段。
  • 全局作用域：所有 API 方法在脚本任意位置均可直接调用，无需传递。
  • 语法支持：完整支持 Java 8 特性，包括 Lambda 表达式、流式 API。
  • 线程模型：事件回调默认在 IO 线程执行。操作 UI 需切换至主线程。

示例脚本
log("脚本开始运行...");
qqToast(2, "Hello World!");

addItem("测试菜单", "onTestClick");

void onTestClick(int chatType, String peerUin, String peerName) {
    qqToast(2, "点击了菜单");
    sendMsg(peerUin, "你好!", chatType);
}

void onMsg(Object msgData) {
    String msg = msgData.msg;
    String peerUin = msgData.peerUin;
    int type = msgData.type;
    
    log("收到消息: " + msg);
    
    if (msg.contains("ping")) {
        sendMsg(peerUin, "pong", type);
    }
}

void unLoadPlugin() {
    qqToast(0, "脚本停止运行");
    log("脚本停止运行");
}
